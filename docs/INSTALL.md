# 测试与安装指南

一共有三种方式把应用装到眼镜上，从开发调试到正式分发依次往后走：

| 方式 | 适合做什么 | 热更新 | 需要上传 |
|---|---|---|---|
| ① 局域网扫码 | 日常开发、改完马上看效果 | ✅ | 否 |
| ② 私有构建（Private build） | 验证 `.ehpk` 打包、权限弹窗、从眼镜主菜单启动 | ❌ | 是 |
| ③ Beta 测试 | 提交审核前做全面验证，或发给朋友测 | ❌ | 是 |

## 准备工作（只需做一次）

1. 手机上安装 **Even Realities App**（版本 ≥ 2.2.10），配对 G2 眼镜，有 R1 戒指的话也一起配对。
2. 用同一个账号登录 [hub.evenrealities.com](https://hub.evenrealities.com)。网页端登录后，账号会自动变成开发者账号。
3. 在手机 App 里打开 **Even Hub** 标签页，确认已经进入开发者模式（能看到「扫码 / Scan QR」入口）。
4. 申请高德 Key：登录 [lbs.amap.com](https://lbs.amap.com)，进入控制台 → 应用管理 → 创建应用 → 添加 Key，「服务平台」选 **Web服务**。
5. 电脑上安装依赖：

   ```bash
   git clone https://github.com/jiangmuran/amap-hud-g2.git
   cd amap-hud-g2
   npm install
   ```

## ① 局域网扫码（开发调试）

手机和电脑必须连在**同一个 Wi-Fi** 下。

```bash
# 终端 1：启动开发服务器。HMR_HOST 填电脑的局域网 IP，这样手机上也能热更新
HMR_HOST=192.168.8.4 npm run dev

# 终端 2：生成二维码
npx evenhub qr --url "http://192.168.8.4:5173"
```

然后：

1. 打开手机 Even App → **Even Hub** → **Scan QR**，扫描终端里显示的二维码。
2. 几秒后眼镜上会出现巡航界面，手机上显示应用的设置页。
3. 第一次打开会让你选 **iPhone / 安卓**，按实际情况选。
4. 在 **设置 → 高德开放平台** 里填入 Key，点「保存并测试」，出现「Key 可用」就说明配好了。
5. 回到首页搜索一个地点 → 选择出行方式 → **开始导航**，然后到户外走一走。

> 局域网里还有一个不需要眼镜的预览方式：`scripts/lan-preview.sh start`。它会同时起手机端网页和官方模拟器（用浏览器访问），详见 README。

## ② 私有构建（真机安装 .ehpk）

```bash
npm run pack          # 生成 amaphud.ehpk（也可以直接下载 GitHub Release 里的文件）
```

1. 打开 [hub.evenrealities.com](https://hub.evenrealities.com)，新建项目。包名要和 `app.json` 里的 `package_id` 一致：`com.amaphud.nav`。
2. 进入项目，切到 **Private builds** 标签页，上传 `amaphud.ehpk`。
3. 手机 Even App → **Even Hub** → **Me → Apps → Private builds**，找到这个构建，点 **Install**。
4. 安装完成后，在眼镜的主菜单里就能找到 **AMAP HUD**，从那里启动。

私有构建这一步会真实走一遍以下流程：
- manifest 校验；
- 网络/定位权限弹窗（请选择允许）；
- 从眼镜主菜单冷启动。

私有构建切到后台后存活时间较短，扛不过审核员做的「锁屏 5 分钟」测试；要验证这一项需要用 Beta 测试。

## ③ Beta 测试 / 正式发布

在门户里把构建切到 **Beta**。Beta 和正式上架是同一条安装路径、同一套生命周期，适合：
- 提交审核前做全面验证；
- 发给朋友一起测试。

如果要正式上架，按 [App Submission & QA](https://hub.evenrealities.com/docs/ship/app-submission) 提交审核。本应用已经满足的几项硬性要求：

- 在根页面双击会弹出系统的退出确认（`shutDownPageContainer(1)`）；
- `package_id` 是合法的反向域名，名称不超过 20 个字符；
- 网络权限用白名单写明域名（`https://restapi.amap.com`），没有使用通配符。

> 注意：高德的**个人认证** Key 只能用于非商业用途。如果要公开上架并有用户使用，需要先完成高德的企业认证和商用授权。

## 眼镜上的操作

| 手势 | 作用 |
|---|---|
| 前滑 / 后滑（镜腿或戒指） | 切换视图：导航 → 全局地图 → 路书 → 仪表 → 周边雷达 |
| 单击 | 执行当前视图的操作（切换地图朝向、全程/附近、翻页、扫描周边…） |
| 单击后长按 | 打开系统菜单：结束导航、重新规划、专注模式、地图朝向、街道底图、周边扫描、返回起点 |
| 长按 | 专注模式下临时唤醒完整 HUD |
| 双击 | 退出（会弹出确认） |

## 常见问题

**扫码后页面是白屏 / 一直加载**
确认手机和电脑在同一个 Wi-Fi，用手机浏览器能打开 `http://<IP>:5173`；电脑防火墙要放行 5173 端口。

**位置偏了几百米**
确认「设置 → 手机系统」选对了。另外，系统的「精确位置」权限需要打开。

**提示「Key 平台类型不匹配」**
Key 必须是「Web服务」类型，「Web端(JS API)」和「Android/iOS SDK」类型的 Key 都不行。

**手机页面顶部提示「眼镜已切换到文本模式」**
这是宿主的已知问题：退出确认框弹出后再取消，图片通道会失效。导航仍然可以继续用（文字界面），完全退出应用再打开就能恢复图形界面。

**配额用完**
个人认证每月：路线等服务 15 万次、搜索 5000 次、天气 5000 次。设置页里能看到本机统计的用量。
